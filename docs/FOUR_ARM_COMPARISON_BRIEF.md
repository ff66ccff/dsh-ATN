# dsh-ATN 四臂比较实施说明

这份文档交给实现代理执行。上一轮（拓扑绑定）完成了结构证明、宿主强制和真实能力探针，唯一未通过的是第 4.5(2) 条准入判据——**该判据本身写错了**，见第 2.4 节。本轮替换该判据并执行四臂比较。

实现代理在动手前必须先完整阅读本文件，并按第 7 节完成标准交付。

- 结构证明 `experiments/results/topology-binding-proof-20261006.json`：5 个 seed 全部 `exceedsStaticDegree=true`、`fixedReachable=false`、`issuedModelCalls=0`、`eligibleSeeds=[17,31,45,59,73]`。

## 2. 本轮已确证的事实

### 2.1 结构证明成立

入口 slot=0、初始 peers=[7,1]、出度上限 2；两个阶段共需 4 个不同持有者的精确事实，所需不同直连边为 4 > 2。固定边集合跨阶段不能更换，因此固定拓扑在结构上无法完成。证明为纯计算，SHA-256 绑定 fixture 与拓扑参数。

### 2.2 宿主强制已实现并确定性验证

revision 3 只接受 `{phase,key}` 事实请求与精确本地事实 `result`；第三方返回值以 `evidence-not-owned` 明确失败。策略在 mutation 临界区内、分配邮件／结算任务之前执行；拒绝不修改网络记录。BIND-ACL 确定性测试验证了非本地事实 `result` 被明确拒绝且无副作用。

### 2.3 真实自适应能力达标

最终探针 4/5 两阶段正确（80%），换边成功率 21/21，最大步数占比 64.58%，全部 cleanup released。seed 73 零换边尝试且未提交，按 `not-observed` 记录，未删除或补跑。

### 2.4 唯一未满足的准入判据写错了

上一轮 4.5(2) 要求"至少一次真实转发拦截"。真实运行的 `evidence-not-owned` 拦截数为 **0**。

**这条判据要求系统出现违规行为才能证明强制生效，方向是反的。** 规则写入共同提示后模型遵守规则，零违规是预期结果，不是强制失效的证据。这是连续第三轮出现同一类错误：用行为代理指标去证明结构性质（P0 的"换边 verdict 不再是 insufficient"、同伴差异轮的"≥4/5 次发生换边"、本轮的"至少一次拦截"）。

**本轮起，结构性质只由结构方法证明；行为指标只用于能力判定。**

## 3. 目标

- **G1 绑定确证**：用构造性参考在两种拓扑上给出对照，使"固定失败是结构性的、不是模型能力问题"成为可离线核验的事实。
- **G2 替换判据**：删除以违规计数为准的准入判据。
- **G3 执行四臂比较**：在准入通过后完成 adaptive / fixed / no-feedback / no-board 各 ≥5 次。
- **G4 成本口径**：报告每臂相对构造性参考的调用数与步数倍数。

## 4. 必须实施的项目

### 4.1 用构造性参考确证绑定（替代违规计数）

要求：

- 把现有的构造性参考策略分别在**固定拓扑**和**自适应拓扑**上运行全部 5 个 seed，使用相同 ACL、相同 fixture、相同预算。
- 参考必须只使用公开元数据与实际收到的 `task`／`result` 构造答案，不读取隐藏答案。
- 预期结果：adaptive **5/5**，fixed **0/5**。
- 判定规则：
  - 参考在 fixed 上**成功** → 绑定失效，四臂比较作废，必须先修强制；
  - 参考在 fixed 上**失败**且在 adaptive 上成功 → 绑定确证，固定臂的结构性失败被独立确认；
  - 参考在 adaptive 上也失败 → 任务或参考实现有问题，先修再比较。

验收测试（零模型调用）：

- 参考在两种拓扑上的逐 seed 结果落盘，含入口步数、消息数、取得的精确事实清单。
- 断言 fixed 参考取得的必需事实数 < 全部必需事实数。
- 断言 adaptive 参考取得的必需事实数 = 全部必需事实数。

### 4.2 替换准入判据

要求：

- **删除** `probeRealInterceptions` 类判据。不得以拦截次数、违规次数作为强制生效的判据。
- 强制生效改由 4.1 的对照确证。
- 新增**事实流正向审计**：对每个真实运行，核对最终答案里出现的每条事实，都能追溯到「其所有者经直连边交付」的记录。审计不通过则该运行不得计入比较。
- 保留可发现性判据（尝试数 ≥1 且成功率 100%，仅 `blocked > 0` 判为可发现性问题），保留结构性证明判据、能力判据与余量判据。

验收测试：

- 审计器对"事实来自所有者直连"与"事实来路不明"两种构造输入给出不同结论。
- 判据实现对"零拦截但事实流审计通过"判为通过，对"零拦截且事实流审计失败"判为不通过。

### 4.3 执行四臂比较

前置条件（全部满足才执行）：

1. 4.1 绑定确证通过。
2. 各比较 seed 的结构证明通过并在汇总时重算。
3. 同模型、同配置、同源码的独立 adaptive 探针 ≥4/5，且最大节点步数 ≤ 预算 80%。
4. 四臂各 ≥5 次、配对 seed 相同、全部节点余量合格。
5. 比较数据自身出现非零 `rejected`（探针的 rejected 不得借用）。

比较执行要求：

- 四臂使用同一模型、同一预算、同一 fixture、同一源码；预算变更必须是显式条件且四臂一致。
- 只使用在探针中达到 ≥4/5 的模型；LongCat 明确排除。
- 失败、超时、工具异常、未知 usage 全部保留，不隐藏。
- 报告必须给出每臂的：两阶段正确率、阶段提交率、`accepted`／`rejected`、换边尝试／成功／拦截、最大节点步数占比、模型调用数、通信交互数与字节数。

### 4.4 成本口径对照构造性参考

要求：

- 报告每臂相对**同拓扑构造性参考**的倍数：模型调用数、协议交互数、传输字节数、入口步数。
- 已知基线：参考在 adaptive 上为 0 次模型调用、入口最大 27/48 步；真实探针每轮 83–102 次准入调用。
- 该倍数用于说明模型的协调开销，**不得**被表述为拓扑收益。

### 4.5 不要用 fixed 臂的失败充当收益证据

要求：

- 固定拓扑在结构上不可完成是**任务设计的结果**，不是自适应拓扑的收益。
- 报告必须把"结构上不可完成"与"自适应完成率更高"分开陈述。
- 真正的收益主张只能在四臂全部完成、且自适应相对**其他非固定对照臂**（`no-feedback`、`no-board`）也表现出一致优势时提出；否则只能陈述为"绑定成立，自适应可完成，其余臂结果见报告"。

## 5. 必须保留的既有语义

- 入口 Agent 由宿主拥有；完成、停止、退休都不 `dispose` 入口。
- 网络记录是唯一原子持久化单元；"检查 + 修改"在同一 mutation 临界区内完成。
- 边是单向的；出生谱系只作追溯。
- 工具身份、发送者、投票者取自真实 live Agent。
- 同伴文本不构成人类授权；请求者评价不构成宿主验收。
- 白板作者权限、精确版本、分页失效与读写计量语义不变。
- 同能力原则：限制的是信息可达性，不是能力。
- `stepBudget` 不得被宣称成 token、HTTP 请求或费用上限。

## 6. 不要做的事

1. 不新增模型工具。
2. 不以违规次数、拦截次数作为强制生效判据。
3. 不通过提高预算让闸门通过。
4. 不改生产默认值。
5. 不删除已有测试，不降低断言强度。
6. 不把固定臂的结构性失败写成自适应拓扑收益。
7. 不删除失败样本或补跑成功样本。
