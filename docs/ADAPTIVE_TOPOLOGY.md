# 最小自适应拓扑

当前源码通过局部运行时遥测、请求者评价、知识指纹、每节点预算和原子认领支持自适应协作。模型工具为 `atn_start`、`atn_status`、`atn_spawn`、`atn_send`、`atn_feedback`、`atn_publish`、`atn_board`、`atn_rewire`、`atn_finish` 九个；宿主验收是可选的更强质量证据，不决定能否重连。出生谱系保留用于追溯，不决定后续协作。[任务验收与观测说明](VERIFIED_COLLABORATION.md)区分执行结果、验收结果与重连观测。

请求者对已收到的完成结果用 `atn_feedback` 记录本地判定；知识持有者用 `atn_publish` 发布有界索引。发现排序先匹配知识与任务文本，再参考真实评价与负载；重连自动选取同一比较契约的本地样本，并把 `requesterEvaluation` 与宿主 `evaluation` 分开保存。两项写入都不发送邮件、不额外唤醒节点。来源、边界与确定性对照见 [P0/P1 机制实验](FEEDBACK_MILESTONE.md)。

## 节点自主决定什么

每个节点有相同的工具能力，可以发现同伴、接取和分配局部工作、替换自己的连接、创建独立节点或申请退休。`atn_status()` 合并邻居、任务、孤儿任务、局部遥测与本节点剩余预算；带查询可发现最多三个相关候选。重复 `query="*"` 会从上批候选之后继续轮转，在状态不变时也能逐步发现其他分支的非邻居 active 节点。游标按网络和调用节点独立保存在内存中，并发查询依次推进；运行时重启后从首批重新探索。普通文本查询保持相关性排序，不推进轮转游标。发现不会建立连接。

`atn_rewire(peers)` 接受完整的新邻居列表，原子替换出边，遵守网络冻结的 `maxCollaborationPeers`（1–4，默认 4）。边有方向：A 选择 B 不会强制 B 选择 A。节点可跨出生分支协作，`[]` 则明确清空出边。无效 id、自身、重复项、超过上限或非 active 节点使整个请求失败。有效重连不需要收益样本、宿主验证器或投票，也不要求每次执行都重连。每次获准调用都记入 `rewireHistory`，包括保持原边集的决定，没有原来的 64 次记录上限。

新节点最初连接创建者及创建者已有同伴；创建者有空位才加入新节点。后续连接由各节点选择。当同伴退出时，运行时只沿这个同伴已知的连接补失活槽，没有全网评分或优化器，也不会主动填满所有空槽。局部补位仍可能选到曾经断开过的同伴；没有永久排除名单。显式 `[]` 保持为空。

同伴退出、自动补位、主动重连和局部工作进展，会在下次实际收件箱输入获准进入模型时合并附加一条摘要。摘要同时包含邻居变化与自动观测的任务数量、开放/提交/失败/不可达状态、延迟、节点步数、重试、恢复及相关下游失败。明细最多八项，提示中每同伴只展开最近两项；`completed` 表示提交，不表示正确。任务步数是任务存续期间持有者计数的差，重叠任务共享观察窗口，不能相加充当独占任务成本或 token 成本。

比较基准和遥测摘要的指纹随正常 Session 输入持久保存，重启后仍有效。多次变化合并为最终观测；未变化则不重复通知。仅经过时间或接收者自己的输入步数变化不会重复注入。被拒绝或取消、没有记入日志的输入不会消耗反馈。这条路径不创建独立邮件、不唤醒空闲节点、不额外调用模型，也不需要宿主检查器。

每个节点有自己的 `stepBudget`，包括入口节点；预算耗尽后停止接新步骤并退休，未完成任务转成可恢复的不可达尝试。最后获准的调用可完成其工具操作。网络的 `stepsUsed` 仍保存累计消耗以便报告，不再用作全网共享预算。该计数只覆盖运行时获准的模型步骤，不测量提供商重试、额外模型调用或真实 token 费用。

空闲节点可用 `atn_status(claimTaskId=...)` 认领相关孤儿任务。原持有者已退休或失败、原尝试失败或不可达且尚无后续尝试时，该任务可见；原子 mutation 队列确保并发认领只有一个成功。认领保留原失败记录和请求者，新任务通过 `retryOf` 关联来源。无需创建者再指派，认领者仍须遵守自身预算并返回结果。

## 连接改变哪些行为

| 行为 | 授权依据 |
|---|---|
| 发起新任务、发送普通通知 | 发送者自己的有效出边；允许发给自己 |
| 返回旧任务结果 | 真实任务持有者发给其记录的请求者，断边后仍可发送 |
| 继续旧任务讨论 | 通知带真实 open 任务 id，发送者与接收者分别是该任务的持有者和请求者 |
| 宿主 API 提交协作计划修改 | 固定全网其他 active/published 节点，全体明确同意；目标、成功标准、约束固定 |
| 已有提案投票 | 原冻结名单，重连与退出补位不会更换名单 |

`peerIds` 保存协作边；`creatorId`、`selectedChildId` 保存出生历史。重连不迁移任务、不取消承诺，也不改变旧提案授权。原有身份、期限、分阶段退休和硬停止机制继续约束执行。治理和续租保留宿主 API，但不再占用默认模型工具；网络完成使用 `atn_finish(scope="network")`，单节点退休使用 `scope="node"`。

兼容旧记录时，缺失的 `peerIds` 从旧出生链邻域初始化一次并持久保存；已存在的空数组保持为空。发现响应统一使用 `neighbours` / `nodes` 和 `candidates` / `candidateNodes`，不再返回旧的 `upstream` / `downstream` 分组。候选摘要可包含已结算任务，让节点发现当前空闲但做过相关工作的同伴。`recentResults` 保持字符串数组，每个摘要以 `[completed]`、`[failed]` 或 `[unreachable]` 标明真实终态；unreachable 任务没有结果正文时使用其任务描述。

持久化 domain 版本仍为 1。新增节点步数、任务计数边界和重连观测均为可选字段，旧记录可以直接读取。没有记录的旧任务成本保持未知，不追溯分摊旧全网计数；旧节点的逐节点预算从新计数开始执行。旧重连审计保留原样，后续新决定才拥有完整运行时观测。

`atn_send(kind="result")` 接受可选的 `outcome="completed"|"failed"`，省略时默认 `completed`；失败必须显式传入 `failed`，正文写着“失败”不改变结算状态。`task` 和 `note` 不接受 `outcome`。结果投递会携带已持久结算的状态，发现摘要也展示该状态，后续是否重试、换人或重连由节点决定。使用稳定 `messageId` 重试时须保持原消息内容及结果状态，省略 `outcome` 与显式 `completed` 等价；同一 id 改成另一结果状态会被拒绝。

## 能力与验证边界

这次演进提供可被模型实际选择、持久化并执行的拓扑。任务分工与拓扑可以共同变化，不需要中心模型安排固定角色或强制轮次。运行时不判断谁是“最好”的合作者，不替模型规划网络，也不以额外评分或奖励机制声称已经产生群体智能。

每次重连冻结旧邻居的局部观测，同时记录新邻居的当前观测。后续任务及步数 mutation 更新该节点最近一次重连的 `observations.after`，该节点再次重连后前一条冻结。数量是调用者对该同伴累计委派任务的计数，延迟/任务步数均值使用最近有界样本；它不是自动匹配工作量的实验，更不是重连的因果效果。宿主验收可补充独立的质量、成本单位与可比任务信息。

确定性测试能验证连接改变通信、断边保留旧任务、逐节点预算、并发认领、无额外调用的反馈及持久恢复。它们不能证明真实模型会选择有用的拓扑，更不能证明完成质量、成本或速度优于 agent team。本轮实验把八节点的出度降到二，初始双向环直径为四，并加入私有证据位置和阶段变化；十六节点的同类环直径为八也有确定性测试。白板跨拓扑可读，禁止白板时知识索引仍可发现，因此这些条件建立了邮件路径的稀缺性，不能直接证明拓扑收益。各臂记录提交质量、消耗、完成时间及实际边变化；保持原边集的调用不算有效换边。详见[完整实验记录](FULL_FEEDBACK_EXPERIMENT.md)。

此文描述 `dsh-atn@0.3.1`（npm 标签 `latest`）中的自适应拓扑。上一版预览 `dsh-atn@0.2.0` 和 Git 标签 `v0.2.0` 不含这些能力。历史验收限制仍见 README 和对应实施报告。

此前最小自适应拓扑阶段通过 173 项测试，覆盖轮转探索、显式失败结果、局部变化摘要、跨分支协作、断边义务、并发重连、退出补位、旧记录迁移和冷恢复。后续 pilot 与本阶段验收机制的验证分别记录，不把历史测试数量当作当前总数。

此前构建后 tarball 的真实 Web profile 安装 smoke 确认过旧版十工具。本轮再次使用当前 tarball 通过真实 dsh Web profile 检查，确认九个 ATN 工具（含反馈、发布和白板）注册、子节点继承及 Standard 隔离。安装 smoke 使用确定性模型；真实模型的群体能力对照另行记录。
